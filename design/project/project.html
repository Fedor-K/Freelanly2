The project

Linear is building a mobile sync engine — offline-first, CRDT-based, the same architecture our web app pioneered. We're looking for one engineer to own the front-end side of it end to end.

You'll be working directly with the founding eng team. This is a permanent role, not a contract, but we welcome people coming from senior contractor backgrounds — many of our team did.

What you'll do:

  • Architect the React Native mobile client around our CRDT sync layer
  • Build conflict-resolution UX patterns that don't feel jarring
  • Ship offline-first features that genuinely work on subway commutes
  • Collaborate with the web team on shared sync primitives

You'll thrive here if:

  • You've shipped offline sync in production (any framework)
  • You think about state machines before reaching for libraries
  • You're EU-based or comfortable in EU TZ
  • You enjoy writing — we communicate async, in long-form

Comp is around $90K/yr equivalent depending on experience and engagement model. Equity available. If interested, send a short note + portfolio. — Sarah
